Baseline: main @ fede417c. Audit findings and evidence in AUDIT_REPORT.md
(round 2 section). 4 P0 issues fixed, 2 P1 issues fixed.

P0-1 tests counted skips as passes
- Reproduced: with NO results/ directory present, the suite still printed
  "14/14 Passed (ALL PASS)" and exited 0, because the Test 13/14 SKIP
  branches only logged and left t*_ok true.
- Added skippedTests counter, a preflight check for the five required data
  files, and a summary that prints PASS/FAIL/SKIP separately. Any skip now
  fails the run. Return value is
  (preflightOk && failed == 0 && skipped == 0).
- Test 13 no longer reads leftover reports on disk. It generates a
  negative-gain report (real gather) and a positive-gain report (synthetic)
  into the sandbox and checks the freshly written wording.
- Verified negative path: deleting real_gather_59x256.csv now yields
  EXIT=1, "Test Results: PASS=14 FAIL=1 SKIP=0",
  "Status: FAILED - required input files are missing".

P0-2 Test 14 strengthened
- Now runs all 6 keep x seed configurations, asserts held-out counts,
  same-seed reproducibility, gain == pocs - linear, and that changing the
  seed actually changes the split and metrics.

P0-3 holdout results archived (new)
- Added runHoldoutBatch() and --holdout-batch. The program itself writes
  results/real_field_holdout/holdout_runs.csv with input SHA1, trace
  counts, samples, iterations, seed, three SNRs, both gains, both RMSEs
  and runtime. No hand-filled tables.
- 6/6 configurations succeed; POCS beats linear interpolation by
  +0.91..+1.30 dB in every configuration. Absolute SNRs are negative and
  are reported as such.
- Two consecutive runs produce identical scientific columns; only
  runtime_ms differs.

P0-4 mask effectiveness regression (new Test 15)
- Two different 64/128 masks now demonstrably change the result:
  linear-interp SNR 0.36 dB vs 12.10 dB (delta 11.74 dB). Four invalid
  masks (missing path, non-binary, wrong count, wrong length) are all
  rejected rather than silently falling back to an auto mask.

P1-5 doc/metric consistency
- scientificplotter.h default arguments were still 14.10 / 12.35 /
  0.9872; updated to 13.90 / 11.83 / 0.9794 / 3.00.
- tspsform.cpp GUI narratives still claimed "14.10 dB, +1.75 dB";
  updated to 13.90 / +2.07 with an explicit note that these are
  synthetic-only numbers and that the real-field result is -0.62 dB.
- README "8.20 dB" (warm-vs-cold difference) corrected to 7.66 dB
  (13.90 - 6.24).

P1-6 result tree semantics
- Real SPS attribute output moved out of results/synthetic/ into
  results/real_sps/attribute_evaluation/. results/synthetic/ now holds
  only the synthetic modules (01, 03). Code, suite checks and the Test 10
