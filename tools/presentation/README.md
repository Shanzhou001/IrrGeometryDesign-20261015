# Frozen presentation reference

rebuild_reference.mjs rebuilds the previously validated seven-slide research reference, preserving its historical numerical claims. It does not claim a new experiment or GUI run. Supply an explicit project root, original template, output, build directory, installed first-party presentation skill and bundled runtime paths. Run with --help for parameters. No user-specific absolute path is embedded.

The required template and F3 figure are included in data/templates. Use the installed Presentations skill finalizer and inspect all rendered slides before delivery. The tool cannot replace physical-amplitude, imaging or field-cost evidence.
