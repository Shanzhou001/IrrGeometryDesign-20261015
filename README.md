# 地震采样点筛选与缺失道恢复

课题：**基于混合优化算法的地震采样点智能筛选方法研究**。作者：吴善州；导师：王华锋；校外导师：范子梁。更新日期：2026-10-26。

项目以固定保留道数和有限评价预算为约束，研究 Jitter 初始化、模拟退火、离散局部搜索与预算回收，并分别检验采样几何目标和隐藏道恢复质量。当前真实资料主线为公开的 Mobil AVO Viking Graben Line 12 子集；二维 SPS 几何作为独立工程扩展。

本轮补充批次已完成 **1215个恢复案例、351个唯一搜索、11725次成功调用**，3掩码种子与双内层分组，86,144文件及4860份预测的独立核验通过。当前项目正式检查通过，Python105项中101通过、4项明确旧RRAW依赖跳过。英文13页和中文六章19页研究初稿已生成并渲染核对；源码、表格和构建入口见相邻论文目录。

这些实验来自同一测线。炮、窗口、隐藏集和掩码种子均不视为独立工区。当前没有证据支持自适应搜索普遍优于 SA、互干度下降必然改善恢复、跨工区有效或已经改善成像质量。

## 快速开始

命令在项目根目录运行。Python 为 3.12；原生 x64 工具链为 VS2008 SP1、Qt 4.7.4。

```powershell
python -m pip install -r requirements.txt
.\build.bat Release
.\build.bat Debug
python -B pipeline.py test
python -B pipeline.py check --full --out checks/new_project_check
python -B pipeline.py viking-v2 --out results/new_viking_v2 --workers 8
```

`check` 默认检查核心实现；`--full` 检查当前项目资料链路；旧 RRAW 另由 `--legacy` 显式检查。具体范围与通过判据见 [RUNNING.md](RUNNING.md)。所有运行使用新的输出目录，冻结批次运行期间保持源码、协议、输入与程序不变。
