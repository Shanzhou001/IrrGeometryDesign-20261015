3. 二维正式实验由单种子扩展到十种子，逐实例归档掩码。

6. 修正参考场、非线性收缩和图件中的不准确表述，界面优先使用增强版结果。
7. 真实 NN-CV 核验遵循 C++ float32、六位有效数字的落盘规则，消除精度格式引起的误报；没有改写实验数值。
8. 统一修改署名，增加跨日期重复补注、Python AST 不变性及旧编码处理回归。

实际坐标目标固定为：令候选数为 N，保留数为 m，`L=N*(x_max-x_min)/(N-1)`，则

`mu = max(d=1,...,N-1) |sum_selected exp(-2*pi*i*d*(x_j-x_0)/L)| / m`。

这对应频率 `k/L` 的一个明确 Fourier 字典。等间距时退化为原序号 PSF，平移与统一单位缩放不影响目标。它不是唯一可能的物理频带定义。物理坐标硬间距约束尚未实现，实际坐标路径会拒绝套用索引硬上限；SPS 优化仍按排序后的接收点索引评价。

重构是非线性曲波 Wiener 型收缩与观测投影的 POCS 式迭代，不能直接借用经典凸 POCS 的收敛保证。真实坐标下使用线性观测算子 A，并以 `u <- u+A^T(AA^T)^(-1)(d-Au)` 施加观测一致性。已知道一致性通过不代表隐藏道已经恢复准确。

## 5. 当前结果与论文可用结论

### 5.1 搜索降低 μ，但 Hybrid 不是当前最优搜索对照

以下为同目标、20 种子的一维均值，μ 越小越好：

|采样率|Jitter 初值|SA-only|Local|Hybrid|Restart|
|---|---:|---:|---:|---:|---:|
|30%|0.324457|0.210820|0.234127|0.218091|0.248095|
|50%|0.229276|0.135955|0.156016|0.139612|0.172618|
|70%|0.228943|0.090327|0.100631|0.092486|0.164489|

Hybrid 相对 Restart 的 μ 改善通过同目标家族的 Holm 校正；SA-only 相对 Hybrid 的 μ 也在三档均更低，并通过该校正。不能把 Hybrid 写成优于所有对照的最优算法。

### 5.2 空间覆盖与 μ 存在代价交换

均匀网格约束研究的十种子均值如下。最大间隔单位为索引，包含两端边界：

|采样率|无约束 μ|软约束 μ|无约束最大间隔|软约束最大间隔|
|---|---:|---:|---:|---:|
|30%|0.2145|0.2320|13.3|5.6|
|50%|0.1400|0.1594|6.6|3.0|
|70%|0.0939|0.1054|5.1|2.0|

软约束减少大空洞，同时提高 μ。硬约束满足配置上限，但 50% 档硬约束 μ 约为 0.4020，说明约束强度需要权衡。默认权重 0.3 尚未证明适合所有数据。

### 5.3 合成重构收益有条件，必须保留强基线

软约束相对 Hybrid 在九个“模型×采样率”组中八组均值提高；倾斜模型 70% 档降低约 1.297 dB。对全部 18 项探索性配对 SNR 比较统一 Holm 校正后，只有两项约束收益达到 0.05：

|组别|软约束相对 Hybrid 的缺失道 SNR 增益|Holm p|
|---|---:|---:|
|三层模型，30%|+2.635 dB|0.03516|
|断层模型，30%|+2.525 dB|0.03516|

断层模型 50% 档均值虽增加约 2.591 dB，校正后 p=0.0625，不能称为显著。SA-only 在九组合成重构中的平均 SNR 都低于 Hybrid，但这九项在统一校正后均不显著。

普通 Jitter、Regular、Random 或 Restart 在多个配置上仍很强。例如三层模型 30%：Hybrid 5.157 dB、软约束 7.792 dB、Jitter 8.348 dB、Regular 9.129 dB。更低的 Fourier μ 并不自动对应更高的本实验曲波重构 SNR；去重后的分组相关系数也呈不同方向。当前目标与重构效果之间的差异本身就是应当讨论的结果。

主一键演示另采用十次基准中 50% 的 μ 最优掩码：全幅重构 SNR 13.19 dB，缺失道 SNR 10.18 dB，缺失道相对线性插值增加 2.52 dB。这是有选择规则的单例，不能代替上述多掩码平均，也不是实测资料恢复成绩。

### 5.4 真实资料：相对线性插值有改善，绝对恢复仍不足

以下为每格十次均值，指标是隐藏实测道的重构 SNR，单位 dB：

|保留道数 / 59|Hybrid|软约束|Jitter|Restart|
|---|---:|---:|---:|---:|
|20|−1.3424|−1.3622|−1.1547|−1.2109|
|30|−0.8930|−0.7917|−0.6435|−0.3795|
|40|−0.3095|−0.3169|−0.0499|+0.0587|

全部七方法、三种保留数形成的 21 组中，20 组平均 SNR 为负；只有 Restart 保留 40 道组略高于零。各组相对线性插值的平均增益约 +0.31～+1.13 dB，但多数仍未超过零填充基线。不同策略的隐藏道集合不同，这些均值评价策略后果，不是完全相同测试位置上的逐点配对。

210 次留出均满足已知道观测一致性。五个单独 CDP 的固定留出重构 SNR 仍约为 −2.44～−1.50 dB；分 CDP 没有自动解决问题。目前不能把恢复失败简单归因于 CDP 混合，也不能宣称已经确定失败原因。

### 5.5 二维与 SPS 支持几何结论，尚未连接成像结论

二维十种子平均 μ：

|采样率|HybridTrue2D|RestartTrue2D|
|---|---:|---:|
|30%|0.166321|0.189476|
|50%|0.109138|0.134305|
|70%|0.072797|0.153311|

当前支持所测 16×16 配置下的二维掩码目标比较，尚未完成任意二维实测坐标设计或三维波场重构。

在相同 SPS 抽稀统计网格中，接收点从 9,072 减至 4,536，平均覆盖次数从约 106.93 降至 53.57，覆盖次数 CV 从约 0.5467 到 0.5446。CV 接近不代表覆盖次数未损失，更不能直接推断成像质量无损或采集总成本减半。
