本报告区分历史 GUI 优化、正式 v4 研究接口及新增 v5 补充协议。源码基线和实际数值证据

## 1. 数学定义及独立证据

正式目标是采样 Fourier 字典的最大归一化非对角列内积，不是历史 `CurveletMiu1DEigen`
粗尺度参考 Gram 差值。二者数值不可混排；GUI 旧函数和正式研究入口均保留。
给定严格递增候选 x、N 个 Fourier 原子、精确 m 个保留点，周期
L=N(x_last−x_first)/(N−1)，频率 k/L，k=0…N−1。
列范数均为 sqrt(m)，因而 Gram 的最大非对角模可归并为 d=1…N−1 的指数和模/m。
负差频率与正差的模相同；d=0 的对角自相关必须排除。

均匀 x_j=x_0+jΔx 时 L=NΔx，恰好退化到索引 FFT/PSF。全保留均匀网格 μ≈0，
全保留不规则网格不必为 0；m=1 时 μ=1。新搜索仅接受 0<m<N，全保留不是优化任务。
DP 单独核验包含 m=N。空掩码不是有效字典。

最大间隔包含左/右边界。最近邻距离在内部取相邻距离较小者，端点取唯一邻居；
CV 使用总体标准差，m≤1 按实现约定为 0，m=2 自然为 0。
软目标 J=μ+λ_gap max(0,g_max/(L/m)−1)+λ_NN CV_NN。
物理域使用物理 gap/CV，索引域使用索引值；不允许把索引硬约束当成米制硬约束。
无量纲不等于采样率无关：改变 m 会改变问题、惩罚分布和统计基线，不能直接跨档排名 J。
这也勘误了旧 `ConstraintWeights` 上方“与采样率无关、可跨档比较”的过强注释。

`research/validation/audit_numerics.py` 用 NumPy 显式复字典 Gram 而非共享 C++ PSF 公式，
复核七点所有非空非满掩码的两域/两权重，共 504 例；再以枚举核验 84 个 DP 问题。
μ/CV/J 最大误差分别约 2.80e−8/5.53e−8/7.06e−8，gap 精确一致。
当前最终程序再次执行相同 588 例通过，不把重跑算新增独立测试。
v4 既有全批独立核验另包含均匀退化、实际坐标、目标/约束和真实导出预测复算。

固定点数硬间隔 DP 以虚拟两端边界构成有向无环路径：F(k,j) 表示恰选 k 点且末点 j；
首点离左界≤G、相邻选点≤G，末点离右界≤G。回溯保证恰好 m 点。
(m+1)G≥孔径仅为必要条件；候选空洞也能造成不可行。新可选集合排除 H 时，
不允许初始化修复偷偷选回 H；不能构造合规初值就明确失败。

## 2. 频带/周期建模敏感性

固定 v4 掩码独立重算半频带、1.5 倍频带及周期取孔径的定义，未用恢复 SNR 选定义。
物理域不同频带/周期与默认 μ 排名的 Spearman 相关只有约 0.260…0.874。
均匀域周期若直接取孔径 (N−1)Δx，同时仍保留 N 个原子，则第 0 与第 N−1 列完全相同，
μ 恒为 1，相关系数未定义。这是可解析的定义退化反例，不是当前周期实现的 Bug。
若改变原子数/频带，应另建协议；不能因为某个替代评分看起来更好就换成正式目标。

数学等价性支持当前离散归一化，但不证明频带适配某个地震资料。
Fourier 几何 μ 也不是曲波观测矩阵 RΨ 的实际全字典互干度，不能直接套用稀疏恢复充分条件。
结果见 `analysis_thesis/band_sensitivity.csv`、`band_rank_sensitivity.csv` 及图 07。

## 3. 方法机制的实际差别

|方法|SA/温度|局部搜索|停滞后|评分后端|
|---|---|---|---|---|
|SAOnly|历史降温，64 次前缀标度|无|继续 SA 到上限|索引 FFT/物理直接求和|
|旧 Hybrid|64 次含初值 SA 前缀|按顺序 ±1 贪心|停止，可能闲置预算|历史后端|
|SA_Budget|全预算温度日程|无|继续 SA|FFT/缓存物理原子|
|Adaptive|minSA=32 且最优停滞12触发|最近空位与全域交换交替|回收预算、精英重置、一次至多两对交换扰动|同 SA_Budget|
|FixedSwitch|每全局阶段固定64个候选评价|同 Adaptive|同 Adaptive|同 Adaptive|
|NoRecycle|同 Adaptive|同 Adaptive|首次局部停滞停止|同 Adaptive|
|AdjacentOnly|同 Adaptive|随机方向，仅 ±1|同 Adaptive|同 Adaptive|
|NoPerturb（v5）|同 Adaptive|同 Adaptive|回收预算但不额外扰动|同 Adaptive|

FixedSwitch 不是旧 Hybrid：其局部提案和预算回收仍不同。
SA_Budget 同时采用新温度/缓存，不能用它对 SAOnly 的质量差异单独证明缓存改善了搜索。
当前未增加新主算法；NoPerturb 仅用于最小机制诊断。没有按外层 SNR 决定保留/删除机制。

## 4. 状态机与预算审查

```text
验证 N,m,权重,坐标,预算；必要时构造可行精确 m 初值
评价初值，e=1；current=elite；准备物理原子（构造时间计入）
while e<B 且提案/时间上限未到：
    SA 从 current 提案；局部从 elite 提案
    保持 m；全部交换点须属于允许候选集合
    廉价可行性检查失败 → 记录提案尝试，不计算 μ
    完整评价候选 → e 增加1，记录阶段和候选
    SA：按 Metropolis 更新 current
    局部：仅精英改善时更新 current
    候选严格改善 elite 超过 1e-8 → 更新 elite，清零停滞
    否则累积精英停滞；局部另累积局部失败
    满足切换条件 → SA 转局部
    局部连续失败到窗口 → 停止或返回 SA，保留 elite
返回 elite；单独报告 e、尝试数、状态、轨迹、时钟
```

温度 T=0.1×(0.0001)^((e−2)/max(1,B−2))，扰动温度有 0.01(1−progress) 下限。
初值计 1 次。扰动候选也完整评价计数；第二对交换若重复第一对源/目标就省略，
第一对始终有效，不会靠第二对抵消。精英保留与 SA 接受劣解分开。
不可行提案和出界方向不计算目标；尝试上限保证退出。重复掩码仍计一次完整评价，
没有使用免费的候选目标筛选或以唯一掩码数冒充评价数。

确认的日志口径问题：v4 Adaptive 的 `currentTrace` 是候选值，旧 SA 的同字段是接受后当前值。
v5 保留旧字段以维持旧 CSV，增加 `acceptedTrace`、阶段、温度、提案尝试与 QPC 墙钟。
不能跨方法直接把历史 `current_objective` 当成同一种马尔可夫链状态。
尝试数定义随提案机制而不同：Adaptive 包括无效局部方向，旧局部计已形成的有效索引交换；
不以不同提案数直接衡量方法效率。目标评价次数才是共同主要预算。
历史v4的旧方法 `sa_evals/local_evals/restart_evals` 还保留默认0占位，不能解释为真的没有执行SA/局部阶段。
本轮不据这些占位字段分析机制；新方法按完整phaseTrace核对，缺失的旧阶段粒度不补造。

新增 eligibility 在初值、全局、局部和扰动均排除 H；唯一可选掩码直接终止，避免空集合取模。
非法/NaN 权重、无效窗口、外层 H 被选中等测试返回非零。相同种子的确定性轨迹可复现。
最终程序完整重放 930 个 v5 非限时搜索案例，掩码、科学列及非计时轨迹逐值一致。

## 5. 机制证据与限制

v5各方法在本协议内共享NumPy生成的分层Jitter初值；v4使用C++的Jitter实现。
两协议不能假设相同seed意味着相同初始mask，也不能跨协议把均值差解释为配对算法改进。

v4 20 种子正式结果仍是主对照：Adaptive 对旧 Hybrid 的 12 个组均值更低，72 项 Holm
族中 6 组显著；对 SAOnly 未显著。新增 B=300 的 10 种子只用于补充/敏感性，
42 项 Holm 校正后没有显著项；其检出力不足，不能解释为所有机制均无效。

Adaptive 与 NoRecycle 截至后者停止时的共同实际评价前缀完全相同，六组平均差恰为 0。
这直接支持“继续使用剩余预算”是最终差异的重要来源，不能把该最终差异全部解释为
更高的前段搜索效率。切换、混合邻域和额外扰动的独立普适收益尚未建立。
NoPerturb 的部分描述性均值更好、部分更差；没有据此替换主方法。

30 ms 顺序 QPC 上限实验的均值约 30.017…30.040 ms，实际评价约 518…633 次。
Adaptive 在此设置的最终 μ 均值更低，不能升格为普遍速度优势：B=100000 的评价温度日程
在提前限时后未完成降温；相同时间不是相同温度进度。结果完整保存在时间表中，
没有以并发恢复耗时排序算法。QPC 包含初始化/缓存，进程墙钟另包含启动/输出。
Windows `clock()` 是旧原生计时字段，不被本轮当成高分辨率 CPU 时间。

## 6. 复杂度与恢复数值

均匀候选每次评分为 FFT O(N log N)，还包括 O(N) 的候选/覆盖扫描。
物理缓存构造/存储 O(N²)，每次完整循环扫描 N(N−1) 个掩码位置，非零项复数累加
O(Nm)，总体最坏 O(N²)；缓存减少三角函数调用，不减少完整评分次数。
DP 最坏 O(mN²) 时间、O(mN) 存储。当前验证规模 N=59/128；尺寸保护不等于任意大规模性能保证。

FDCT wrapping 正反变换与收缩/观测投影每次迭代在工作数组上约 O(Nt Nx log(Nt Nx))，
曲波系数冗余影响常数与内存。实际坐标投影 A_K^T(A_K A_K^T)^−1 由三对角系统求解。
独立稠密 NumPy 对照原生冷启动、一次迭代、零收缩的实际输出，两例最大误差
6.01e−8 和 4.99e−10；最终当前程序也重做通过。
纯变换另用独立解析复数组，覆盖64×32、64×64、250×128、256×128、499×128及3/4尺度、
8/16方向的20种组合；Release/Debug相对L2误差均不超过2.30e−15，系数能量比偏差不超过4.00e−14。
该检查不含阈值或观测投影，避免把求解器的一致性测试当成变换本身的唯一验证。

迭代固定次数停止，收缩阈值随余弦日程下降；日志相对步长不是隐藏误差停止准则。
Wiener 型非线性收缩与曲波框架不保证经典凸 POCS 的全局收敛。
原单位一致性判据已按已知道尺度修复；它只修复单位相关失败状态，不能解释既有负 SNR。

## 7. 文献关系

扰动—局部搜索的基本框架已有 [Lourenço、Martin、Stützle, Iterated Local Search](https://arxiv.org/abs/math/0102188)。
局部稀疏表示与最大缺口控制的地震采样动机可对照
[Hennenfent、Herrmann, Simply denoise: wavefield reconstruction via jittered undersampling](https://slim.gatech.edu/Publications/Public/Journals/Geophysics/2008/hennenfent08GEOsdw/paper_html/paper.html)。
本项目使用的变换依据 [Candès、Demanet、Donoho、Ying, Fast Discrete Curvelet Transforms](https://curvelet.org/papers/FDCT.pdf)。
这些文献不证明本项目组合机制普遍最优，也不为当前真实资料编码或非凸迭代背书。
