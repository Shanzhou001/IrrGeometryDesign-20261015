# 硕士论文代码审查与修改方案（2026-10-24）

论文题目：《基于混合优化算法的地震采样点智能筛选方法研究》。审查基线为 `72d79a2`，工作区开始时干净；历史正式协议为 `physical_psf_v3`。本计划在实施前记录，后续结果无论正负均保留。

|优先级|已确认的代码事实或问题|拟实施措施|验收证据|
|---|---|---|---|
|P1|Hybrid 在 64 次评价后永久切换局部搜索，局部邻域为按索引扫描的 ±1 移动；停滞后会留下未使用预算。|保留旧方法，新增停滞触发切换、混合交换邻域与预算回收的自适应方法；分别关闭机制做消融；增加同温度日程 SA 对照。|共同初值、种子、评价上限，逐次轨迹、实际评价次数与耗时、多种子配对统计。|
|P1|真实恢复 SNR 多数为负，尚无保留数据内的参数选择流程；不能靠外层隐藏道挑选参数。|参数化曲波收缩与初始化，新增训练/验证/测试隔离：候选仅在外层保留道内验证，选定后才对外层测试评价；记录所有候选及固定基线。|隐藏幅度变更不影响所选参数或预测；观测一致性、尺度等变性与指标独立复算。|
|P1|物理 Fourier 目标已有直接计算验证，但搜索仍在每次评价先计算无用的索引 FFT；物理硬间隔未实现。|去除物理路径冗余 FFT；验证候选坐标/权重有限性；以动态规划构造精确点数的米制硬间隔可行初值。|均匀退化、平移/单位缩放、显式字典 Gram、小规模穷举可行性对照。|
|P1|软权重既有扫描把两权重绑定为同值，主要只评价几何；不能说明对恢复的影响。|分开 gap/NN 权重，保留未支配解，增加同掩码端到端合成恢复与相关分析；避免按测试 SNR 选权重。|保存各权重的 μ、间隔、CV、SNR 和掩码；分模型、采样率分析，注明探索性。|
|P2|核心搜索未拒绝 NaN/无穷权重；内部重构直接访问首行，输入不合规可能越界。|入口校验与数值有限性保护；增加边界回归；避免改写历史数值或 GUI 接口。|非法输入测试、Release/Debug 构建、旧版结果兼容核验。|
|P2|59 道资料混合五个 CDP，缺少当前窗口的时差/相干性证据；原 SEG-Y 非标准字段容易被误用。|校验原始各道头、稳定排序及输入转换一致性；在仅训练道上描述零时差/有界时差相关性、频谱与振幅。|输入和原始文件哈希、全段/裁窗区分、CDP 子集不计作独立资料。|
|P2|README 和方法草稿仍含 v2 数量与坐标口径。|以实际新实验重写现行说明，单列历史 v3 结果与新协议；更新进展和图件。|文档数字由新归档生成，清楚区分降 μ、改善覆盖和提高 SNR。|
