## 实际坐标目标的准确定义

候选坐标严格递增，记为 `x[0..N-1]`，固定字典周期：

`L = N * (x[N-1]-x[0]) / (N-1)`。

字典包含频率 `k/L`，`k=0,...,N-1`；采样集合的目标是归一化字典 Gram 非对角元素的最大模，等价于：

`mu = max(d=1,...,N-1) |sum(exp(-2*pi*i*d*(x_j-x_0)/L))| / m`。

这是一种明确固定、可复核的物理坐标 Fourier 字典选择，不代表唯一正确的物理频带。等间距坐标时与原序号 PSF 完全一致；不规则候选点全保留时，字典列未必正交，不能要求 μ=0。

优化变量仍是既有实测候选位置的二值子集。Jitter 和 Regular 初值按候选序号构造，后续优化目标及软约束使用实际坐标；没有在两个实测位置之间自由新增点位，不将本实现称为连续自由坐标优化。

物理软约束为：

`J = mu + lambda_gap*max(0, max_gap_m/(L/m)-1) + lambda_nn*NN_CV_physical`。

默认两权重均为 0.3。最大间隔包含左右边界；所有距离来自实际坐标。平移和统一单位缩放不改变 μ、CV 与 J；最大间隔按单位同比变化。新 C++ 回归以直接复数和、等间距等价性、仿射变换及已知距离算例验证；Python 另用显式字典 Gram 复核。

索引硬约束继续用于原有均匀网格研究。实际坐标路径明确拒绝把索引硬上限混当米制上限；连续坐标硬约束尚未新增。SPS 接收点优化仍使用排序索引，不在本轮声称完成二维连续物理坐标设计。

## 新旧结果的可比范围

- 一维同目标消融继续使用 `classic_psf_v2` 的搜索定义和 200 次评估上限，历史数字可以独立复核。

- 真实研究改用物理坐标目标，不能把新版 μ 与旧版 `mu_index_psf` 作为同一指标直接比较。
- 新增 SNR 配对比较覆盖三个模型、三档采样率和两个对照，共 18 项统一 Holm 校正，明确标为探索性分析；同一固定模型上的种子反映掩码变化，不增加地质模型或真实资料来源数。

## 真实资料诊断

原始资料仍只有一份 59 道文件。5 个 CDP 分别为 237、238、239、240、241，对应 8、15、15、14、7 道；相邻 offset 间距为 26～182 m。分组只是同一资料内的子分析。

固定诊断使用 seed=20261023、40 次迭代、各组约保留三分之二实测道，统一使用原有 0～1.020 s 窗口，未根据这些 SNR 选择参数：

|组|保留 / 总道数|线性插值 SNR dB|POCS SNR dB|相对插值增益 dB|
|---|---:|---:|---:|---:|
|混合 CDP|39 / 59|−0.82|0.19|1.01|
|CDP 237|5 / 8|−2.95|−2.33|0.62|
|CDP 238|10 / 15|−3.40|−1.92|1.48|
|CDP 239|10 / 15|−2.08|−1.50|0.57|
|CDP 240|9 / 14|−2.61|−1.77|0.85|

这六组是单固定划分的描述性诊断，不能直接比较组间难度，也不能据此确定恢复失败原因。分 CDP 后没有自动获得正 SNR；当前结果不支持把问题简单归因于 CDP 混合。

机器可读诊断和完整指标位于新结果目录的 `real_data_audit/audit.json`、`AUDIT.md`。

其中道数、振幅和相邻相关性描述原始 250 样点资料；0～1.020 s 窗口、固定种子与 40 次迭代指留出重构检查。原始整段相关性不能直接当作裁剪窗口内的相关性。
