## 3. 已完成的研究方法与算法实现

### 3.1 固定采样数与初始方案

研究采用 0/1 掩码表示保留道，约束保留数严格为 `m`。搜索通过交换一个已选点和一个未选点维持采样数，支持规则、随机、Jitter 等初始化或对照方案。

对比已逐步从单次“优化前后 μ 值”扩展为：共享初始掩码、固定种子、统一目标、相同评价上限，并同时记录实际消耗的评价次数。不同协议即使种子编号相同，也不能假定初始掩码相同。

### 3.2 Fourier/PSF 几何目标

一维物理坐标协议使用排序候选位置 `x_j`，坐标周期为 `L = N/(N−1) × (x_max−x_min)`，目标为采样后归一化 Fourier 字典的最大非对角 Gram 幅值。均匀网格下可归约为掩码非零 Fourier 系数的归一化最大幅值，即相应 PSF 旁瓣指标。

已实现或明确的内容包括：

- 均匀网格采用 FFT 评价；物理坐标采用预计算相位缓存。
- 验证显式字典等价性、均匀网格等价性，以及平移和一致单位缩放下的不变性。
- 对不规则坐标，全采样也不必具有零互干度。
- 频率范围和周期定义属于模型选择。周期直接取端点孔径时，均匀网格可能出现重复字典列，使 `μ = 1`。
- 此目标描述 Fourier 几何性质，与实际曲波合成—观测算子的互干度存在区别，因此不能直接推出曲波恢复保证。

当前一维物理坐标评分实现仍按频率扫描完整掩码，最坏复杂度为 `O(N²)`；相位预计算减少了重复三角函数运算，不能据此将整个评分过程写成仅 `O(Nm)`。

### 3.3 覆盖指标和约束

已将互干度之外的布局性质纳入评价：

- 最大间隔包含采样区域两端边界，而非只统计内部相邻点。
- 最近邻距离变异系数 `CV_NN` 描述局部间距离散程度。
- 软目标包含最大间隔惩罚和最近邻变异惩罚；v4 保留 `λ_gap, λ_nn ∈ {0, 0.1, 0.3}` 的九组权重研究。
- 一维物理最大间隔硬约束采用精确保留数动态规划判定可行性并构造初始解；候选坐标中的空洞也会影响可行性。

不同权重对应不同目标，不能把它们的总目标值与无惩罚的 μ 排名混在一起，也不能依据外层隐藏道 SNR 回选最有利权重。

### 3.4 自适应混合搜索及消融

当前 `adaptive_hybrid_v4` 实现包括 SA、历史最优解保留、停滞触发的局部搜索、混合交换邻域、预算回收及扰动。默认设置为每个全局阶段至少 32 次 SA 候选评价，连续 12 次无最优改进后进入局部搜索；局部连续失败后将剩余预算交回 SA。

实现记录候选、接受状态、历史最优值、阶段和评价计数。初始评分计一次评价，重复掩码的完整评分也计数；无效或不满足硬约束的提议另计尝试次数，并由上限防止无限尝试。

| 方法或设置 | 对照目的 |
| --- | --- |
| SAOnly | 历史纯模拟退火基线 |
| Hybrid | 固定 SA 前缀后执行旧局部搜索，停滞可提前终止 |
| SA_Budget | 共享自适应实现的评分后端和完整预算温度进度，关闭局部搜索 |
| Adaptive | 停滞切换、混合邻域、预算回收和扰动的组合 |
| FixedSwitch | 固定阶段切换，区别于旧 Hybrid 的整体行为 |
| NoRecycle | 局部停滞后终止，用于检查继续使用剩余预算的影响 |
| AdjacentOnly | 限制局部邻域 |
| NoPerturb | 关闭额外扰动 |

算法术语已经需要随实现统一：历史汇报和接口中保留“CG”“SA+CG”等名称，但 `OptimizeMiu.h` 明确说明相关旧局部方法是**坐标贪心 ±1 移动，并非标准共轭梯度法**。当前论文应准确描述离散交换或局部搜索；共轭梯度的理论性质不能直接作为此实现的依据。

## 4. 已完成的重建与评价流程

### 4.1 FDCT 恢复与观测一致性

已实现曲波变换、非线性系数收缩、逆变换和观测一致性迭代。论文草稿描述的默认配置为 4 个尺度、粗尺度 16 个角向划分、最高频尺度采用小波、40 次迭代，并采用预设阈值调度。

物理不规则坐标通过工作网格和线性插值观测矩阵连接，使用观测 Gram 系统进行一致性校正。输入缩放和初始化只使用本次提供的观测值。

恢复过程的阈值收缩不是对固定凸集的正交投影，因此未建立经典凸投影算法的收敛保证。FDCT 可逆、迭代变化小或已知道拟合准确，也不足以证明隐藏道预测准确。

### 4.2 外层隐藏集与内部选择

已实现将采样搜索和恢复器选择分开评价的流程：

1. 外层隐藏位置 `H` 不参与搜索、恢复输入、缩放和参数选择。
2. 保留位置 `K` 内再划分训练与验证部分。
3. v5 固定候选池为零预测、坐标线性插值、默认曲波和冷启动曲波；用内部验证误差选模型及 `[0,1]` 范围的幅度系数。
4. 使用全部 `K` 重拟合，冻结选择结果，对未知位置应用幅度系数，并保留已知观测。
5. 在外层隐藏位置计算 SNR，保留负值。对非零目标，零预测对应 0 dB。

原生恢复调用前，未知列振幅被置零，避免求解器读取隐藏真值。历史全局归一化链与原始振幅隔离链分别保留诊断，不能把理想化的尺度抵消解释为严格无泄漏。

v4 使用过更宽的内部候选池，其“选择后恢复”结果与 v5 的固定候选池不能互换。

### 5.1 v4：20 种子搜索对比

| 项目 | 草稿中的设置 |
| --- | --- |
| 均匀候选 | `N=128`；保留 `38/64/90` 道 |
| 物理候选 | 59 个排序头字段 offset；保留 `20/30/40` 道，物理意义有待确认 |
| 评价预算 | `B=200` 和 `B=600` |
| 重复方式 | 每组 20 个配对计算种子 |
| 统计比较 | 6 类 Adaptive 对照 × 2 坐标域 × 2 预算 × 3 密度，构成 72 项 Holm 校正族 |

草稿结果：Adaptive 相比旧 Hybrid，在全部 12 个“坐标域—预算—密度”组中最终平均 μ 更低，其中 6 项对比通过 72 项比较族的 Holm 校正；尚未建立稳定优于 SAOnly 的结论。

代表案例为均匀候选、`m=38`、`B=600`：

| 对比：Adaptive 减去对照 | 平均 Δμ | 95% bootstrap 区间 | Holm 校正后 p |
| --- | --- | --- | --- |
| 旧 Hybrid | −0.015055 | [−0.019027, −0.011239] | 约 0.0001373 |
| SAOnly | −0.000301 | [−0.003289, 0.002413] | 1 |

Δμ 为负表示 Adaptive 更低。结果支持相对旧混合方法的改进，不能延伸为所有混合机制都有独立收益。

### 5.2 v5：机制、参数与共同实际评价次数

草稿记载 v5 搜索预算为 300、每组 10 个种子。默认设置下比较 8 种方法或变体，Adaptive 另有 6 组最小 SA 长度与停滞窗口设置，共形成 840 个搜索案例。

- 42 项检验族中无比较通过 Holm 校正，最小校正后 p 为 0.08203125。10 对非零配对的精确双侧检验分辨率不足以支持该比较族的首项拒绝，不能据此认定机制完全无效。
- Adaptive 与 NoRecycle 在后者终止前的轨迹完全相同，6 组共同实际评价次数下的平均差均为零。这是预算回收主要减少提前停止、避免闲置预算的直接证据。
- 切换策略、混合邻域和扰动的普遍独立收益尚未建立；NoPerturb 的描述性均值有好有坏。
- 30 ms 限时试验约消耗 518–633 次评价，但温度调度仍以 `B=100000` 为参考，短时运行未走完退火过程。该结果属于条件性计时诊断，不能作为普遍加速结论。

### 5.3 联合合成研究：几何改善能否传递到恢复

草稿中的合成数据为 `256×128` 阵列、4 ms 时间间隔、12.5 m 道间距，包含倾斜、弯曲和断层事件三类解析模型，每类两种结构设置，各配两档噪声条件。这些是解析事件场，并非波动方程正演数据。

共同隐藏集为零起始索引 `{4,12,…,124}` 共 16 道；从其余 112 个允许位置选 `38/64/90` 道，Fourier 字典仍定义在完整 128 个位置上。另外保留“在全候选上选点、在各自补集上评价”的传统任务，两种评价目标应分别解释。

总计 1080 条联合记录，来自 12 个结构—噪声条件、3 档密度、3 个掩码种子、5 种方法和 2 种评价设计。90 个几何掩码在不同信号条件间复用，因此不能将记录数视为独立地质样本数。

统计时先平均掩码种子，再合并同一干净结构的两档噪声，最终只有 **6 个干净结构模板**作为分析单位。该依赖修正是在初步分析之后引入，属于透明修正后的探索性分析。

Adaptive 在共同 `H` 上的平均 SNR 记载如下，单位 dB：

| 保留数 / 全候选数 | 固定曲波恢复 | 内部选择后恢复 |
| --- | --- | --- |
| 38/128 | 10.3200 | 10.4690 |
| 64/128 | 12.5619 | 12.4396 |
| 90/128 | 13.7482 | 13.7975 |

内部选择没有保证外层改善：中等密度的平均值反而略降。24 项模板级比较均未通过 Holm 校正；6 个非零配对下，首步校正的理论最小 p 已达 0.75。不同条件下 μ 与 SNR 的相关方向也会变化，支持“几何代理指标与恢复目标存在偏差”的判断。

### 5.4 单一真实来源的条件性诊断

草稿研究的真实文件只有 59 道、每道 250 个样点。预设了原生 8 ms 全段、8 ms 裁窗、4 ms 时间上采样全段和 4 ms 上采样裁窗四种设置，每窗对应 3 档保留数、每档 2 次几何划分，共 24 个诊断。

| 观察项 | 草稿记录 |
| --- | --- |
| 固定默认恢复的负 SNR 案例 | 17/24 |
| 内部选择后的负 SNR 案例 | 1/24 |
| 原生全段、20 道：固定 → 选择后 | −0.2745 → 0.3480 dB |
| 原生全段、30 道：固定 → 选择后 | 0.2962 → 0.6702 dB |
| 原生全段、40 道：固定 → 选择后 | 0.9441 → 1.1809 dB |

这些分数反映有限的隐藏道预测能力，并未建立高保真波场恢复。内部幅度收缩可能降低误差，却不能保证保幅；时间上采样不增加实测信息，不同窗口的分数也不能相减后视为同任务算法增益。

草稿还记载：将隐藏振幅干预为 `13y+7` 时，v5 原始振幅链的模型选择不变、最大预测差为零；历史全局归一化链仍有约 0.007482 原始单位的预测差，约为原始峰值 7155 的 `1.046×10⁻⁶`。这些历史隔离结果需要原始归档支撑，当前未重新执行。

## 6. 新增二维空间坐标方向

当前源码已有独立的 **`SpatialFourier2D_v1`** 协议，使用实际 `(x,y)` 坐标定义有限二维 Fourier 字典，不能混入冻结的一维 v4/v5 统计。

已完成的实现包括：

- 默认每轴最多 8 个字典原子；两轴均非退化且达到默认上限时，共 64 个原子、112 个利用共轭对称保留的非零差频。
- 相位缓存和交换增量更新，减少每个候选评分时的全量求和。
- 固定采样数的 SA 与“固定 SA 前缀＋贪心随机交换”比较，共享初始化、随机种子及 SA 前缀，记录完整评价轨迹。
- 接入 SPS 几何实验，按接收点二维坐标去重，导出坐标、字典定义、掩码、评分和轨迹；现有入口使用 50% 接收点和 200 次评价。
- 显式 Gram 对照、增量评分等价、平移与坐标缩放不变性、非法坐标、保留数和预算等回归检查。

已有核心日志显示这些测试通过。但 9072 点规模测试实际使用的是代码生成的 `126×72` 坐标网格，缓存 1,016,064 个复数值，执行 200 次评价；日志约 0.084 秒的 CPU 时间仅适用于该次合成规模检查。它不能被描述为“9072 个野外测点的完整工程验证”。

当前 SPS 实验中的 `IndexRegular`、`IndexJitter` 仍基于坐标排序后的索引生成，其名称不能解释为严格的二维空间均匀采样或空间 Jitter。二维有限字典也不等同于完整地震频谱，当前尚未形成二维覆盖硬约束与恢复质量的完整论证。

### 8.3 真实资料解释仍未确认

依据英文草稿与现有来源校验代码，待解决的问题包括：

- 头字段声明样本格式码 1（IBM 浮点），历史解码器却采用小端 IEEE 单精度；多种解释都能产生有限值，振幅看起来合理不足以确认编码。

- 59 道分属 5 个 CDP，分别为 8、15、15、14、7 道；按 offset 排序后相邻位置混合 CDP，不能直接当作单一共中心点道集。
- 坐标差与 offset 存在约 100 倍关系，坐标标量、单位及参考系统未确认。

当前代码要求正式真实资料运行提供绑定源文件 SHA-256 的来源声明；显式使用 `--allow-unconfirmed-real` 时，结果标为敏感性诊断，不能成为已确认野外效果证据。声明模板位于 `src/research/data/source_confirmation.example.json`，需要填写编码、采样间隔、单位、几何说明、确认人和证据来源。
