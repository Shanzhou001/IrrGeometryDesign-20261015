# 毕业论文思路与大纲

论文题目：**基于混合优化算法的地震采样点智能筛选方法研究**

## 一、总体思路

围绕“在保留点数和计算预算有限的条件下，如何筛选地震采样点，以及筛选后的布局能否改善缺失道恢复”展开研究。以 Jitter 生成初始方案，结合模拟退火与离散局部搜索优化采样布局，再通过几何指标、重建实验和软件应用评价方法的效果与适用范围。

## 二、技术路线

**候选点与数据准备 → 固定采样数建模 → Jitter 初始化 → SA 全局搜索 → 停滞触发局部交换与预算回收 → 输出采样方案 → 缺失道恢复 → 对比分析与系统展示。**

二、需要回答的三个问题

1. **有限预算下如何有效搜索？** 研究全局探索与局部精化的切换、历史最优解保留和剩余预算回收，分析改善来自搜索策略还是更多实际评价次数。
2. **如何兼顾低相干性与空间覆盖？** 在 Fourier/PSF 互干度之外，引入含边界最大间隔、最近邻距离变异和可行性约束，讨论不同指标之间的权衡。
3. **几何指标改善能否带来重建收益？** 在相同隐藏位置上比较缺失道 SNR 和误差，分析信号结构、采样率及恢复配置对结果的影响。

实施时把握以下要点：

- 用 0/1 掩码表示采样方案，通过已选点与未选点交换，严格保持采样数。
- 以 Fourier 互干度为主要几何目标，结合覆盖惩罚或一维物理最大间隔约束。
- 对搜索方法采用共享初始方案、配对种子和等评价预算，并补充共同实际评价次数的对比。
- 用曲波恢复及线性插值等基线评价缺失道；内部参数选择只使用已观测数据，外层隐藏数据只用于最终评价。
- 将数值正确性检查、算法效果比较和工程功能验证分别报告。

正文之外按学校要求设置中英文摘要、参考文献、致谢和研究成果；详细参数、复现步骤与补充检查可放入附录。

搜索实验中的种子是计算重复；合成数据中的噪声或掩码重复不能直接算作独立地质样本。真实资料编码和几何未确认前，相应结果用于条件性诊断。

## 六、可凝练的研究贡献与写作重点

1. **预算感知的混合筛选方法：** 明确全局搜索、局部搜索与预算回收的配合方式，用等预算和共同实际评价次数解释效果来源。
2. **物理坐标与覆盖约束建模：** 在固定保留数下结合互干度、边界间隔与局部间距指标，并通过独立数值构造核验实现。
3. **从筛选到恢复的评价与工程实现：** 建立共同隐藏集和观测数据内部选择流程，分析几何指标的作用边界，完成软件集成与二维扩展。

以上作为贡献组织方向，具体创新性应结合文献和补齐后的实验确定。现有结果支持讨论相对旧混合方法的搜索改善，尚不支持预设“稳定优于纯 SA”或“互干度下降必然提高恢复精度”。
